Interaction coverage combines scripted browser checks, visual review and an interactive in-app browser keyboard review; it is not an assistive-technology user study. The interactive review moved Robo, inspected text-map cells without moving Robo, navigated lessons, changed gamma from 0.9 to 0.95 with ArrowUp, saved a prior prediction, entered a temporary lecture session and stepped/paused/cancelled real training. It found foundation prediction focus loss and disabled laboratory-control focus loss. The expanded scripted test also found concept checks moving focus to the heading. These were corrected; three dedicated focus rechecks pass. `../interactive-keyboard-review.json` records the observed trace and limitations. The in-app export download event timed out; separate Playwright export tests verify contents. Reopening the interactive browser for a final manual focus check failed with webview attach timeouts, so that final manual recheck is unrun; the automated focus recheck is separate evidence.

Existing browser journeys also cover skip links, export, mobile touch emulation and reduced motion. Task-10 checks add Escape/return-focus on the lecture dialog, keyboard raw-data pagination, screen-reader state text and complete local map alternatives. Automated axe scans supplement these interactions; no blanket WCAG certification is claimed.

Native screen-reader sessions, physical touch devices, Firefox/WebKit and instructor/student usability pilots have not been run in this task. External lecture PDFs are not cached or claimed to work offline.

# Deep-learning implementation contracts

Task 07 adds lessons 09–10. Production remains static HTML/CSS/vanilla JavaScript with one shared environment. The neural library is imported and initialized only when a DQN worker initializes; tabular, linear and policy lesson execution does not load it. Task 10 additionally prefetches the built neural assets into Cache Storage for complete-course offline use; caching does not execute the module. `src/agents/deep/schema.js` and validation are pure data code. `registry.prepareLearner` dynamically imports `deep/learner.js`; the worker uses the CPU backend, including on machines without WebGL.

## Numerical contract

- TensorFlow.js core and CPU backend are pinned to 4.22.0. The gradient registry is explicitly loaded with the neural module. Official references: [backend and memory management](https://www.tensorflow.org/js/guide/platform_environment), [worker execution](https://www.tensorflow.org/js/tutorials/training/web_worker?hl=en), [training and autodiff](https://www.tensorflow.org/js/guide/train_models).
- Full observation vector includes normalized x/y and every enabled consumed-collectible, battery and remaining-time variable. The supported six-cell DQN map enables position only; a generic encoder fixture checks the other variables. Coordinates alone do not support transfer to arbitrary unseen maps.
- MLP: 2 → 16 ReLU → 16 ReLU → 4 linear outputs; 388 parameters. The toy table has 24 entries. Seeded Glorot-uniform kernels and zero biases; no pretrained weights. TensorFlow uses float32. Four action values come from actual network inference; overlay Q arrays are refreshed display caches.
- `y = r + gamma * (1 - terminated) * max Q_bootstrap(next)`. External rollout cutoffs retain bootstrap. Targets are computed before differentiation and treated as constants in all variants. Loss is the mean half-squared residual. A constant-rate TensorFlow SGD optimizer updates connected parameters. There are no momentum slots; logical optimizer iterations are saved. Recreating SGD's unused internal iteration counter has no effect on a constant-rate update, and exact seeded continuation is tested.
- Defaults: alpha .03, gamma .9, epsilon .2, seed 11, cap 60, buffer 256, batch/warmup 16, target interval 40 optimizer updates. One update per real interaction after warmup. Capacity 32–2048; batch 4–32; interval 1–200. Hard target initial copy is not counted as a periodic copy. No target means pre-update online bootstrap, still detached.
- Replay is a bounded serializable ring with monotonically increasing sample IDs. Uniform replay samples with replacement. The ablation uses a matched-size batch of the most recent chronological samples, preserving warmup and optimizer budgets. Replay RNG, network initialization, environment and agent RNG streams are separately derived and saved. Rendering consumes none of them.
- Fixed topology and finite bounded data are validated before allocation. Imports contain numbers, not executable graphs or remote model URLs. Checkpoints include online/target weights, SGD configuration/count, ring/cursor/seen IDs, replay RNG, initialization provenance, visits, actual metrics, current episode/environment/action RNG and failure evidence. Episode reset preserves learned state; reset learning starts a separately versioned experiment. Old schema-1 exports remain valid.

## Workers, evaluation and resource bounds

Training yields after at most 32 transitions or about 8 ms; an individual transition can exceed that soft time bound. Step/Episode/batch/Pause/Resume/Cancel/Evaluate share the existing protocol. Async neural initialization has a generation token. Identity, command IDs and response sequence reject stale results. Cancel retains learning. Replacement/disposal frees network variables and optimizer tensors; evaluation copies only the online weights and releases that predictor on completion/cancel/replacement. Worker termination also releases its process-owned tensors.

Evaluate runs five independent held-out environment/action roots using frozen greedy selection, epsilon zero, ties up/right/down/left. It has no learning API. It changes no training weights, replay, targets, counters or RNG. A timed-out evaluation return is the observed partial sum, not a true terminal return.

Every temporary TensorFlow allocation is within `tf.tidy`; persistent variables and the optimizer are explicitly disposed. Loss history retains the latest 256 optimizer steps, without smoothing or replacement points. Other existing limits remain: 2,000 episode rows, four interactive experiments per lesson, three comparisons, ten evaluations, 16 MiB export. Bounded buffers are engineering choices for this tiny browser exercise, not performance promises for large networks. Full browser heap/GC behavior is distinct from TensorFlow live tensor counts.

## Failure and comparison semantics

Nonfinite loss/gradient/weights or gradient norm above 1e6 or any map-state |Q| above 10000 stops the run. This is an explicit diagnostic guard, not silent gradient clipping. The failing interaction is retained; last finite online weights are restored. No optimizer success metric is invented for a rejected update. Saved failure evidence blocks continued training until a fresh experiment. Failed comparisons retain the checkpoint/configuration/seed and remain incomplete; they are not silently omitted from a supposedly complete result.

Lesson 09 compares tabular Q and neural Q. Lesson 10 compares replay+target, chronological+target, and replay+online-bootstrap. Each receives five independent training seeds, shared evaluation roots, three checkpoints and exactly 60–1500 real interactions per agent (default 600). Reused samples are computation, not new environment experience. Neural warmup means neural and table update counts differ, and the UI reports those counts. The two DQN ablations differ in exactly one factor from the reference.

Training returns, neural loss and frozen evaluation results are separate plots/tables. Episode smoothing is a trailing arithmetic mean of at most seven complete/capped returns; raw rows are retained. Neural loss and equal-interaction evaluation are unsmoothed. Stability summaries report actual last-256 loss ranges, Q magnitudes, target copies, replay fill and five-return empirical variance per independently trained agent. These are descriptive observations, not convergence certificates, confidence intervals or learned distributional predictions. The challenge checks the measured winner (including ties) plus a concept; no required return or predetermined winning method.

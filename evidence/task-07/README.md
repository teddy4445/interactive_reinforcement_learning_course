# Task-07 evidence

All lesson records here are disposable **developer QA artifacts**, not student progress, authenticated grades or learning-effectiveness results. The application does not seed new users with these records. Raw numerical data comes from actual local workers; no neural checkpoint or learning curve is bundled as a substitute for live training.

- `browser-qa-deep.json`: both complete six-stage lesson journeys; 25 from-scratch comparison runs (five independent seeds per variant; paired roots across variants) at 600 real interactions each, three equal-budget evaluation checkpoints, interactive neural runs, earlier imported lesson records and ungraded QA reflections. Each comparison has five training roots and five fresh evaluation roots per checkpoint.
- `browser-benchmark.json`: actual Chromium version, Windows/CPU/RAM, config/seed/runtime/backend, four repeated 600-interaction runs, initialization/compute/wall timings, TensorFlow tensor counts, raw weights/loss history/evaluation and main-thread timer-gap measurements. This is a small known-map benchmark, not a universal speed or convergence claim. The latest executed benchmark overwrites earlier executions of the same fixture.
- `tensor-memory-unit.json`: five actual Node/Vitest CPU cycles with warm live tensor counts and post-disposal counts. This measures TensorFlow tensors/bytes, not all browser heap objects or GPU memory.
- `neural-animation-replay.json`: actual identical checkpoint digests across 100 ms, 800 ms and display-off modes. Fingerprints are accidental-corruption/reproducibility aids, not signatures.
- `early-lesson-requests.json`: real browser request capture for lessons 01, 04 and 08; no TensorFlow/neural chunk request.
- `source-review.json`: local PDF hashes, physical pages visually inspected, scope correction and the unavailable fresh web-reader attempts. Source notes are in `docs/DEEP_REFERENCE_AUDIT.md`.
- `visual-review.json`: separate keyboard Step/Pause/Cancel review, actual acknowledgment/completion latencies, mobile overflow and axe checks. A fault-injection screenshot is explicitly named `deep-failure-fault-injection.png`; it is not an observed naturally unstable benchmark seed.
- `checks/`: commands that actually ran, including retained failures. `TASK_STATUS.md` distinguishes earlier full regressions from final affected reruns. No skipped command is a passing check.
- `screenshots/`: new DQN lesson evidence plus earlier lesson/browser regressions. Focused new files include `lesson-09-network-inspector.png`, `lesson-09-actual-neural-update.png`, `deep-source-and-observe.png`, `deep-mathematics-focused.png`, `deep-measured-stability-table.png`, `deep-map-and-recorded-update.png`, `deep-live-loss-plot.png`, `deep-training-evaluation-plots.png`, `deep-experiment-controls.png`, `deep-inspector-390.png`, `deep-comparison-mobile.png`, and both `lesson-09-complete-desktop.png` / `lesson-10-complete-desktop.png`.

No deployment, host integration, live ACML edits, GPU/WebGL parity claim, native-device browser test, screen-reader user test, or student pilot is represented by these artifacts. Instructor review of activity alignment remains outstanding. Lesson 11 remains unavailable.
